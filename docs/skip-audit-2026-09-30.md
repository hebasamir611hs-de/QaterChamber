## Read this before trusting the table

- **This is triage, not a verdict.** Buckets come from regex rules over each skip's reason text. Bucket-level agreement on a hand-checked stratified sample was **28/32 (88%)**; all 4 disagreements were rows left `UNCLASSIFIED` that should have been bucketed — i.e. the tool fails conservatively, it did not put a test in the wrong bucket.

- **17 skips carry NO reason string at all.** `standards.md` requires the exact blocking reason on every skip. These need a reason regardless of how they bucket.
